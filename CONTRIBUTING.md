# Contributing

Contributions are welcome.

1. Fork the repository.
2. Create a feature branch.
3. Keep changes focused and documented.
4. Run `python -m compileall app.py altamimi_report` before submitting.
5. Open a pull request describing what changed and why.

Features for mass-reporting, credential collection, anti-detection, proxy rotation for evasion, or automated abuse are out of scope for this project.
